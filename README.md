A tiny program that drops one line summing up the week into `/output/entry.txt` — the win, the fail and the chaos — for the Your Week in One Line bounty on make.fun.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
